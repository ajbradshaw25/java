# Java Paint

A simple Java Swing paint program with a resizable brush, color picker, eraser, undo, clear, and PNG open/save support.

## Instructions for Build and Use

Steps to build and/or run the software.

1. Open a new terminal.
2. enter in the following:
3. javac PaintProgram.java
4. java PaintProgram

## Instructions for using the software:

1. Have Fun! Draw and Create to your hearts content!
2. There are many colors to pick from, you can choose different brush sizes, an eraser, undo, and you can open files into the program. Additionally you can also save your work as a PNG.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* You need to have Java and Visual Studio Code installed onto your laptop or PC.
* You then will need to integrate Java into Visual Code by installing the Java extensions.
